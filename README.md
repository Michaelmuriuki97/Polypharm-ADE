# Polypharm ADE – Smart Clinical Support System

**Live Website:** [https://polypharm-ade.vercel.app](https://polypharm-ade.vercel.app)  
**Creator:** Gachoki Michael Muriuki ([GitHub Profile](https://github.com))

## Overview
Polypharm ADE is a smart clinical support system and medication-safety platform designed to help prevent adverse drug events (ADEs) among patients on polypharmacy, particularly elderly populations. It supports patients, caregivers and healthcare professionals in organizing medication records and preparing for informed clinical consultations.

## Key Features
* **Medication Safety Centre:** Plain-language educational guidance on medicine labels, side effects, safe storage and medication reviews.
* **My Medication List:** A private, session-only tool to organize prescription and non-prescription medicines into a printable record for doctor or pharmacist visits.
* **Smart Medication Safety Checker (Clinical App):** Retrieves available FDA drug-label details to flag potential drug interactions for clinical review.
* **Kenya Public Safety Updates:** Live pharmacovigilance reporting snapshots integrated from the Pharmacy and Poisons Board (PPB) PvERS dashboard.

## Repository Structure
* `frontend/` – User interface and clinical support web application
* `backend/` – API services and clinical logic
* `mobile/` – Mobile application components

## Disclaimer
*This platform is a clinical support system and research prototype. It does not replace professional medical advice, diagnosis or a comprehensive medication review by a licensed pharmacist or prescriber.*
